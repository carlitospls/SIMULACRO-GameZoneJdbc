# SIMULACRO · Cómo abrirlo

1. Descomprime. Te queda `SIMULACRO-GameZoneJdbc` con `pom.xml` directamente dentro.
2. IntelliJ → **File → Open** → esa carpeta (la que tiene el `pom.xml`).
3. Run → `localhost:8080` → comprueba que se ven Juegos y Plataformas **antes** de tocar nada.
4. **Git → GitHub → Share Project on GitHub**, nombre `SIMULACRO-GameZoneJdbc`, **Public**.
5. Abre `ENUNCIADO.md`, apunta la hora y empieza.
6. Al terminar cada cambio: **Ctrl+K → Commit and Push** (un commit por cambio).
